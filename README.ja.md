# video-director

**主な対象モデル：Claude Opus 5.5 · Claude Code 向け**

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

**video-director は、主に Claude Code 上の Claude Opus 5.5 向けに作られています。** モデルを導いて、短い動画をコード（HTML、Canvas、SVG、Three.js、GSAP、Remotion）として作成し、1 フレームずつ MP4 にレンダリングさせます。ローンチフィルム、プロモーション、解説動画、データストーリー、キネティックタイポグラフィ、キャラクターやイラストのショート、ループ動画、SNS 向けのリールに対応しています。

このスキルは **Claude Opus 5.5** を監督兼コーディングエージェントとして扱います。映像を数値で計画し、決定論的に組み立て、見ることも聞くこともできない部分は測定します。理由を添えた原則、各フェーズにゲートを設けたワークフロー、2 つの QA スクリプトを備えています。コピーするためのショットライブラリは、意図的に同梱していません。

## 推奨モデル：Claude Opus 5.5

**推奨する構成：Claude Opus 5.5 を選択した Claude Code。** Opus 5.5 に動画のブリーフを渡すと、スキルが計画、アニメーションのコードの作成、レンダリング、結果の確認、具体的な欠陥の修正までを導きます。ほかの有能なコーディングエージェントもこのワークフローに従えますが、**主に想定しているモデルは Claude Opus 5.5 です**。

これは指示と QA のためのスキルであり、モデルの同梱や、ホスティングされた動画生成サービスではありません。出力は、利用できるコードの実行環境とレンダリングツールにも左右されます。

## インストール

Claude Code で **Claude Opus 5.5** を選択し、スキルのフォルダーを個人のスキル（またはプロジェクトの `.claude/skills/`）にコピーします。

```bash
git clone https://github.com/win4r/video-director.git
```

```bash
cp -R video-director/video-director ~/.claude/skills/
```

Claude アプリでは、内側の `video-director/` フォルダーを zip にして、カスタムスキルとしてアップロードします。

スクリプトには `ffmpeg`/`ffprobe` と、`numpy` と `Pillow` を入れた Python 3 が必要です。HTML の作品をレンダリングするには、Playwright と Chromium を入れた Node が必要です（または Remotion を使います）。`faster-whisper` はナレーションの確認用で、任意です。音声には任意の音声合成（TTS）を使えます。

## 使い方

Claude Code で **Claude Opus 5.5** を選択した状態で、普通の言葉で動画を頼みます。このスキルは、1 行の依頼にも応えるように設計されています。

- 「うちの CLI のために 15 秒のループするローンチ動画を作って。必要なことはすべて README に書いてある。」
- 「ブルームフィルターのしくみを説明する、約 30 秒のナレーション付き解説動画が欲しい。16:9 で。」
- 「subscribers.csv から、うちの公式アカウント向けに 20 秒のリールを作って。誠実な内容にして。」

既存のコードで作った動画のレビューや修正もします（「テンポが遅く感じる」「テキストが読めない」など）。チェックは自分で実行することもできます。

```bash
python3 video-director/scripts/check_timeline.py timeline.json
```

```bash
python3 video-director/scripts/qa_video.py film.mp4 --out qa/ --beats timeline.json
```

## 評価の結果

各ラウンドでは、3 つのブリーフを構成ごとに 1 回ずつ実行しました。測定できるアサーションはスクリプトのチェックで採点し、残りはどの実行がどれかを知らないブラインドの採点者が採点して、投稿したい作品を選びました。

| ラウンド | 比較 | 合格したアサーション | ブラインドでの好み | コスト |
|---|---|---|---|---|
| 1 | スキルあり vs スキルなし | 28/28 vs 25/28 | 2–1 でスキルあり | 時間とトークンが約 2 倍 |
| 2 | 現在のスキル vs ラウンド 1 のスキル | 30/32 vs 26/32 | 3–0 で現在のスキル | ほぼ同じ |

ラウンド 1 では、スキルが制作の基本（黒い最初のフレーム、Reels のキャプションの下に隠れるテキスト、小さすぎる音声）を捉えることがわかりました。同時に 2 つの穴も見つかりました。11 秒まで出てこないタグラインと、「false positive」と一度も言わない解説動画です。ラウンド 2 では、これらを修正するルールを追加しました。フックと行動喚起は、音声オフの状態で 3 秒までに、測定したサイズとコントラストで画面に表示されます。視聴者が検索する用語は、話されて表示されます。ラベルが、まだカウント中の数字の上に重なることはありません。構成ごとに 1 回の実行なので、これらは測定値ではなく方向性として扱ってください。キャラクターやイラストの作品、修正、ライブページについてのガイダンスはラウンド 2 の後に追加したもので、まだ評価していません。これらの結果は、Claude Opus 5.5 とほかのモデルとの統制された比較を示すものではありません。
